# Code of Conduct

## Standard

Keep project work direct and respectful. Do not harass, threaten, dox, spam, or post private data.

## Scope

This applies to issues, pull requests, code review, and BBTSL project spaces.

## Reports

Report behavior issues to the maintainers. Include links, screenshots, or message IDs when safe.

Maintainers may hide, close, or remove content that harms the project or its users.
